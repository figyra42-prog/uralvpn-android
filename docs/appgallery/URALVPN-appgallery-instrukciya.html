1. Регистрация и подтверждение личности

  1. Открыть https://developer.huawei.com → «Зарегистрироваться», создать HUAWEI ID.
  2. Если регистрация по телефону выдаёт ошибку — регистрироваться по email и с включённым VPN (не российский IP).
  3. Войти в кабинет, открыть AppGallery Connect: https://developer.huawei.com/consumer/en/service/josp/agc/index.html
  4. Кабинет попросит «Подтвердите личность, чтобы начать» — нажать и пройти:
  5. тип: Индивидуальный разработчик (потом не меняется);
  6. паспорт, селфи, при запросе — банковская карта для сверки имени.
  7. Статус «Выполняется подтверждение личности…» — ждать 1–2 рабочих дня, ответ на email.

Пока подтверждение не одобрено, создание приложения недоступно — это нормально.

2. Создание приложения

  1. После одобрения: AppGallery Connect → My apps («Мои приложения»): https://developer.huawei.com/consumer/en/service/josp/agc/index.html#/myApp
  2. Кнопка New app («Создать приложение»).
  3. Заполнить:
  4. Package name: app.uralvpn.next — точно, после создания изменить нельзя;
  5. App name: UralVPN — быстрый VPN;
  6. Category: Tools / Инструменты;
  7. Default language: русский;
  8. Platform: Android.
  9. Сохранить — откроется карточка приложения с левым меню.

На странице «Сертификаты, ID приложения и профили» создавать ID приложения HarmonyOS не нужно: наш APK — Android. «Устройства» и «Профили» тоже не нужны — APK подписан нашим ключом.

Не писать в названии и описании: «обход блокировок», «обход запретов», «доступ к заблокированным сайтам». Использовать: «стабильный VPN», «защищённое соединение», «быстрый доступ».

Про оплату: не упоминать продажу подписки внутри приложения (это вызовет требование встроенных покупок Huawei). Нейтрально: «Подписка оформляется на сайте сервиса».

4. Загрузка APK и отправка на проверку

  1. Слева Release → App Release → Upload → выбрать UralVPN-universal.apk.
  2. versionCode должен быть больше предыдущего (у нас он растёт автоматически).
  3. Заполнить «что нового» (из description.md).
  4. Submit for review («Отправить на проверку»).

Срок модерации — обычно 1–3 рабочих дня.

5. Если откажут

Частые причины и что делать:

Причина Что сделать
«VPN/обход блокировок» в описании переписать нейтрально, убрать эти слова
Продажа цифровых товаров вне IAP убрать упоминание покупки в приложении
Нет политики конфиденциальности указать https://servisbot.staryi.org/legal.html
Несовпадение названия с APK название в карточке = название приложения
Скриншоты не того размера взять из docs/appgallery (450×800)

После исправления — снова Submit for review.

6. После публикации

  • Обновления: загружать новый APK в App Release, versionCode растёт.
  • Ссылка на приложение в AppGallery появится в кабинете (App information → App link).
  • Её можно добавить на сайт и в бота рядом со ссылкой на APK.
